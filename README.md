# Mi Portafolio Digital

Portafolio web personal desarrollado con React y Vite para presentar mis proyectos, conocimientos técnicos y trayectoria en desarrollo web.

## Tecnologías

- React
- Python
- JavaScript
- CSS
- Vite

## Ejecutar el proyecto localmente

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm run dev
```

Genera la versión de producción:

```bash
npm run build
```
